A toaster's own error message, in 40 characters, written by a program the grader
runs twice. The line is composed from a maintenance fault (code, condition, and the
appliance's admission) in `main.ts` and rendered deterministically — no network, no
clock, no randomness. The joke is deliberately a *service* fault rather than a
bread pun: the toaster reports its crumb tray is full and concedes that the crumbs
are its own element shedding, so it is the cause of its own repair ticket.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
